# FastAPI API для управления отелями

REST API для управления информацией об отелях, построенный на фреймворке FastAPI.

## Обзор

Проект предоставляет CRUD-операции для записей об отелях:
- Получение списка отелей с фильтрацией и пагинацией
- Создание новых записей об отелях
- Обновление отелей (полное и частичное)
- Удаление отелей

В данный момент используется хранение данных в памяти, инфраструктура PostgreSQL подготовлена для будущей интеграции.

## Технологический стек

- **FastAPI** - веб-фреймворк
- **Pydantic** - валидация данных
- **SQLAlchemy** - ORM (подготовлен для PostgreSQL)
- **Alembic** - миграции базы данных
- **Uvicorn** - ASGI сервер

## Структура проекта

```
src/
├── main.py              # Точка входа приложения
├── config.py            # Управление настройками
├── db.py                # Настройка базы данных
├── api/
│   ├── hotels.py        # Эндпоинты отелей
│   └── dependencies.py  # Зависимость пагинации
├── schemas/
│   └── hotels.py        # Pydantic модели
├── models/
│   └── hotels.py        # SQLAlchemy ORM модель
└── migrations/          # Alembic миграции
```

## Запуск приложения

Режим разработки с автоперезагрузкой:
```bash
uvicorn src.main:app --host 127.0.0.1 --port 8000 --reload
```

Продакшн режим:
```bash
uvicorn src.main:app --host 127.0.0.1 --port 8000 --workers 3
```

## Документация API

Swagger UI доступен по адресу: `http://127.0.0.1:8000/docs`

## Эндпоинты

| Метод | Путь | Описание |
|-------|------|----------|
| GET | /hotels | Список отелей с фильтрацией и пагинацией |
| POST | /hotels | Создание нового отеля |
| PUT | /hotels/{id} | Полное обновление отеля |
| PATCH | /hotels/{id} | Частичное обновление отеля |
| DELETE | /hotels/{id} | Удаление отеля |
